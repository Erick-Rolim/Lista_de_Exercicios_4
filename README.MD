# Meu Perfil Profissional

Este é um projeto de página de perfil pessoal criado como parte do curso de Dev Full Stack Jr. O objetivo é demonstrar habilidades em HTML5 semântico e CSS3 avançado, incluindo Flexbox, CSS Grid, responsividade e animações.

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização, layout responsivo e animações.
    * **Flexbox e CSS Grid:** Para criação de layouts complexos e alinhamento de itens.
    * **Variáveis CSS:** Para um tema de cores fácil de manter.
    * **Media Queries:** Para garantir a adaptabilidade em diferentes tamanhos de tela.
    * **Transições e Animações:** Para uma experiência de usuário mais dinâmica e interativa.

## Estrutura do Projeto

* `perfil.html`: O arquivo principal que contém toda a estrutura do conteúdo.
* `styles.css`: A folha de estilos que define a aparência e o comportamento do site.
* `/images`: Pasta para armazenar imagens, como a foto de perfil e ícones.

## Como Visualizar

1.  Abra o arquivo `perfil.html` em seu navegador de preferência.
